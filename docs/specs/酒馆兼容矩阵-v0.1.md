# 酒馆兼容矩阵

- 版本：0.1
- 日期：2026-09-23
- 状态：v0.1 兼容规格
- 范围：酒馆角色卡、Worldbook/Lorebook、Preset、正则后处理和第三方 UI 扩展的导入、适配与边界。
- 原则：兼容优先保证数据不丢失和语义不越权，不承诺酒馆内部 JavaScript 在本项目中原样运行。

## 1. 兼容等级

| 等级 | 含义 |
| --- | --- |
| 直接兼容 | 导入后保留原始数据，核心字段可以直接参与运行，不需要用户重写 |
| 适配兼容 | 可以导入，但需要转换为本项目的资源、ContextPolicy 或规则模型；导入时显示差异 |
| 保留兼容 | 字段原样保存并可导出，但当前 Runtime 不执行其行为 |
| 不承诺兼容 | 依赖酒馆页面、内部对象、STscript 或任意代码执行，不能直接运行 |

未知字段不得静默丢弃。导入结果必须保存 `sourcePayload`、`normalizedPayload`、`extensionPayload`，并生成兼容报告。

## 2. 角色卡

| 资产或字段 | 等级 | 处理方式 |
| --- | --- | --- |
| 角色卡 V1 JSON | 直接兼容 | 转换为 `CharacterDefinition` 和 `AssetRevision` |
| 角色卡 V2 JSON | 直接兼容 | 保留 V2 原始字段，标准字段进入规范化对象 |
| PNG 内嵌角色卡 JSON | 直接兼容 | 读取 PNG 元数据，保留图片作为角色头像 Artifact |
| `name` | 直接兼容 | 角色名称 |
| `description` | 直接兼容 | 角色设定和身份资料 |
| `personality` | 直接兼容 | 角色性格材料 |
| `scenario` | 直接兼容 | Story 初始背景候选；不直接写成已发生事件 |
| `first_mes` | 直接兼容 | 可作为首个 Turn 的角色输出候选或初始消息，需由用户确认提交 |
| `mes_example` | 直接兼容 | 作为示例材料，不伪装成历史事件 |
| `alternate_greetings` | 直接兼容 | 可选择的开场候选 |
| `system_prompt` | 适配兼容 | 转为角色或 Story 级 ContextPolicy 材料，不能越过 Actor 权限 |
| `post_history_instructions` | 适配兼容 | 转为对应 Agent 的末尾指令；隐藏内容仍受知识边界约束 |
| `character_book` | 适配兼容 | 转为 Story 绑定的 Worldbook 资源 |
| `extensions` | 保留兼容 | 保存到扩展字段；已知扩展由适配器单独解释 |
| `creator_notes` 等创作者字段 | 适配兼容 | 默认作为资源说明，不自动交给角色 |

角色卡中的设定、示例和作者说明不是同一种材料。导入器必须标明来源，不能把所有文本拼成一个不可区分的角色 Prompt。

## 3. Worldbook / Lorebook

一个 Story 可以同时绑定多本 Worldbook。每本书保留自己的版本、优先级、启用状态和条目，不在导入时永久合并。

| 字段或能力 | 等级 | 处理方式 |
| --- | --- | --- |
| entry content | 直接兼容 | 作为 `WorldRule` 或候选上下文材料 |
| primary keys / keywords | 适配兼容 | 生成关键词激活条件 |
| secondary keys | 适配兼容 | 生成附加条件，按 AND/OR 配置保存 |
| constant | 适配兼容 | 默认视为本书启用期间的高优先级条目，仍受 Token 预算约束 |
| selective | 适配兼容 | 需要满足选择性激活条件 |
| recursive | 适配兼容 | 支持有限轮次递归，必须设置最大深度和重复检测 |
| scan depth | 适配兼容 | 映射为扫描的最近 Turn/消息范围 |
| insertion position | 适配兼容 | 映射为 ContextPolicy 插槽，不允许把秘密插入 Actor 禁止读取的区域 |
| depth | 适配兼容 | 映射为历史消息相对位置；无法精确映射时报告差异 |
| order / priority | 适配兼容 | 转为材料优先级和稳定排序键 |
| probability / activation chance | 适配兼容 | 保留随机激活配置；激活结果写入执行快照，重试不能重新随机 |
| 角色级 Worldbook | 适配兼容 | 绑定到指定 Actor 或 CharacterDefinition |
| Persona 级 Worldbook | 适配兼容 | 绑定到 UserPersonaDefinition |
| Chat 级 Worldbook | 适配兼容 | 绑定到 Story 或 Branch |
| 书本启用/停用 | 直接兼容 | 作为 StoryResourceBinding 保存，切换从下一个 Turn 生效 |

Worldbook 条目进入上下文前必须经过 Story、Branch、Scene、角色权限和预算过滤。导入的 `constant` 也不能绕过 Actor 的知识边界。

## 4. Preset

Preset 在本项目中转换为 `ContextPolicy`。它可以改变材料如何编排，但不能改变事实提交和权限规则。

| Preset 能力 | 等级 | 处理方式 |
| --- | --- | --- |
| system prompt | 适配兼容 | 进入指定 Agent 的规则材料 |
| prompt order | 适配兼容 | 转为 ContextItem 稳定顺序 |
| prompt role | 适配兼容 | 映射为 system/user/assistant/tool；不允许以 role 绕过权限 |
| character position | 适配兼容 | 映射为角色定义材料插槽 |
| persona position | 适配兼容 | 映射为用户角色材料插槽 |
| history format | 适配兼容 | 转为历史渲染器配置 |
| Author's Note | 适配兼容 | 转为作者材料或输入规则，明确可见范围和作用域 |
| Post-History Instructions | 适配兼容 | 转为指定 Agent 的末尾规则 |
| Instruct Template | 适配兼容 | 只在 Provider 支持时使用；否则生成兼容警告 |
| Story String | 适配兼容 | 转为消息编排模板；不允许直接读取过滤前数据 |
| 常用宏 | 适配兼容 | 只执行声明式安全宏；未知宏保留并报告 |
| 模型参数 | 直接兼容 | 映射到 ModelConnection/ExecutionProfile，未知参数保留 |
| 模型专用隐藏参数 | 保留兼容 | 保存但不保证执行 |

Preset 不能修改以下硬规则：Actor 知识隔离、Branch 隔离、Turn 提交边界、重大决定确认、用户角色控制权和事件来源校验。

## 5. 正则后处理

正则后处理提供适配兼容，但只支持声明式规则，不执行导入资产中的任意 JavaScript。

支持的规则至少包括：

- 输入或输出阶段：`beforeModel`、`afterModel`、`beforeDisplay`。
- 目标范围：指定 Agent、指定 Actor、指定 Artifact 类型。
- 正则表达式、替换文本、启用状态和顺序。
- 是否只影响展示，或允许作为模型输入材料。

规则必须写入执行快照，重试使用同一规则版本。规则不能修改正式事件、角色权限、作者指令可见性或 StateProjection；需要这些能力时使用后端插件和受控 mutation。

## 6. 第三方扩展 UI

酒馆第三方扩展 UI 不直接兼容。原因是它们通常依赖酒馆的 DOM、前端状态、事件总线和内部运行时对象。

本项目提供等价的 UI Extension API。酒馆扩展需要被改写为本项目插件，注册到明确插槽：

- `story.sidebar`
- `story.inspector`
- `story.input.before`
- `story.input.after`
- `story.turn.actions`
- `story.artifact.actions`
- `settings.panel`

扩展 UI 只能通过 Host API 读取状态、提交用户命令和展示结果，不能直接修改数据库或伪造 Runtime Event。原始酒馆 HTML/JavaScript 可以作为源码参考，但不能在核心前端中直接注入执行。

## 7. 导入、导出和报告

导入流程：

1. 读取源文件并保留原始字节或 JSON。
2. 解析标准字段和已知扩展。
3. 生成规范化资源版本。
4. 生成兼容报告：已支持、已适配、仅保留、被拒绝字段。
5. 由用户确认 Story 绑定、Worldbook 启用状态和 Preset 生效范围。

导出时优先导出原始兼容格式；不能表达的本项目字段进入扩展字段或附带 manifest。导出不得把角色私有记忆误写成 Worldbook 公共条目。

## 8. MVP 验收

- 能导入 V1/V2 角色卡和 PNG 内嵌角色卡。
- 能同时绑定多本 Worldbook，并按作用域、关键词和优先级激活。
- 能导入 Preset 的系统提示词、消息顺序、历史格式、Author's Note 和模型参数。
- 未知字段可在导出或兼容报告中找回。
- 声明式正则可以执行；任意 JavaScript 不会被自动执行。
- 第三方 UI 必须通过 UI Extension API 适配，不承诺原样运行。
